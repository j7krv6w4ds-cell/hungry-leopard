# Hungry Leopard

Hungry Leopard — a Himalayan-themed slingshot game (snow leopard vs goats). Built with Matter.js.

Play by dragging the snow leopard and releasing to launch it at mountain goats and structures. This is a small web prototype designed to run in desktop and mobile browsers.

Files:
- index.html
- styles.css
- main.js

To run locally: open index.html in a modern browser. For mobile, open the file in Safari/Chrome on your device.
